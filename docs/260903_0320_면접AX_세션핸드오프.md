## 4. ③ 팀 연속 배치 — 엔진을 안 고치고 화면 계층에서

`arrange.ts` 는 1차 편성 **결과 위에서** 자리를 맞바꾼다. 목적함수를 두고 **나아질 때만** 옮긴다.

```
팀 덩어리 28 → 21 · 하루 두 번 나오는 면접관 5명 → 1명 · 엔진 ③ 6 → 2 · ①② 0 유지 · 52ms
```

지키는 것 셋 — 하나라도 깨면 정리가 아니라 재편성이 된다.
① 학력 구간 밖으로 안 내보낸다 ② 팀·면접관 중복을 안 만든다 ③ 확정(`pinned`)은 안 건드린다

**순진한 방식은 오히려 나쁘다.** 「쪼개진 팀을 주 덩어리에 붙인다」만 하면 시간축은 붙지만
조가 분산돼 엔진 ③ 이 6→13 으로 악화한다. 조 = 물리적 방·링크(D6)라 방을 옮기면 면접관이
옮겨 다녀야 한다.

**빈 슬롯 최소화를 뺀 이유(D25).** 켜면 빈칸 20→16 을 얻는 대신 팀 덩어리가 24→25 로 는다.
빈칸을 실제로 좌우하는 것은 **조 수**다 — 조 하나를 줄이면 빈칸 20→12 로 떨어지고 일수는 3일 그대로다.

## 5. ④ 단계적 확정과 재통보

```
1일차 확정  →  그날 배정을 「통보 내용」으로 찍어 둔다
             카드에 확정 표시 · 탭에 배지 · 시간표 설정 잠김(D22)
        ↓
카드를 옮김  →  막지 않는다. 「재통보」 딱지 + 요약 칩 + 목록
        ↓
2·3일차 다시 편성  →  확정분 + 손질분 고정, 나머지만 재배치
```

**재통보로 잡는 것 세 가지** — 옮겨진 사람 · 배정이 취소된 사람 · **확정한 날짜에 새로 들어온 사람**.
셋째가 빠지면 구멍이 난다: 재편성이 확정된 날의 빈자리를 채우면 그 사람 본인은 통보 전이라
괜찮지만 **그 팀 면접관은 이미 받은 일정에 면접이 하나 늘어난다**. 실데이터에서 실제로 재현됐다
(나보람 — 1일차 08:00 4조에 새로 배정됨).

**보장은 「통보된 사람이 안 움직인다」이지 「그 날짜가 얼어붙는다」가 아니다.** 브라우저 검증도
그 기준으로 잰다(`.cell-card.confirmed` 만 비교).

## 6. 전형 설정 — 17가지가 화면으로

정적 그림이던 「전형 설정」을 실제 화면으로 만들었다. 엔진 cfg 를 그대로 옮기고,
**시간표 계산은 엔진에게 시킨다**(`previewOf` 가 `Sched.schedule([], cfg)` 를 부른다) —
같은 규칙을 두 벌로 두면 화면이 보여 준 시각과 실제 편성이 조용히 갈라진다.

```
A 면접 기간   시작일 · 일수(0=자동) · 주말 건너뛰기 · 쉬는 날(공휴일)
B 일일 슬롯   프리셋 · 세션 수 · 조 수 · 면접 시간 · 휴식 · 시작 시각 · 점심 · 오전 세션 수
C 팀 회신 마감일
D 편성 규칙   학력 분리 + 분리 단위 · 면접관 중복 검사 · 첫 타임 회피 · 팀 연속 배치 정리
\+ 전형 이름 · 조별 화상 링크(접기) · 지난 설정 불러오기
```

**공휴일은 엔진에 없다.** `dateOf()` 는 토·일만 건너뛴다. 그런데 편성 로직은 날짜 인덱스(0·1·2)만
쓰고 실제 날짜는 표시용이라 **화면 계층에서 `dates` 만 다시 만들면**(`withDates`) 편성표·엑셀·
PNG·통보에 전부 전파된다. 엔진은 그대로 뒀다.

**설정을 안 건드리면 편성 결과가 한 글자도 달라지지 않는다** — 테스트로 고정해 뒀다.

## 7. 지원자 상세와 이력서 원본

취합파일은 **467행 × 52열**이고 52열이 전부 화면에 실린다(빈 열 3개는 자동으로 빠진다).

- **날짜가 엑셀 일련번호**로 온다(`생년월일 36609` → `1994-03-18`). 같은 열에 문자열 날짜도 섞여 있다
- 값이 익명화 코드(`성별A · 과정1 · 결과P`)라 **있는 그대로** 보여 준다 — 추측해 라벨을 붙이면 더 위험하다
- 역할 필터(D24)는 **데이터 단계에서** 뺀다. 화면에서 숨기는 게 아니다

**이력서 원본** — `data/lg_resumes_pdf/{지원자번호}_{한글성명}.pdf` 467개(81MB).

```
GET /resumes/{지원자번호}  →  200 application/pdf
GET /data/취합파일.xlsx    →  403  (그대로 막혀 있다)
```

- **번호로만 찾는다.** 맥에서 만든 한글 파일명은 자소가 분리(NFD)돼 화면의 이름(NFC)과 안 맞는다
- `server.fs.deny` 가 `data/` 를 통째로 막고 있어 이 미들웨어가 유일한 통로다. 요청은 숫자만 받고
  실제 경로는 우리가 만든 색인에서 꺼내므로 경로를 거슬러 올라갈 수 없다
- ⚠️ **개발 서버 전용이다.** 81MB 를 빌드 결과물에 넣지 않으려는 것. 배포하려면 그때 다시 정해야 한다
- ⚠️ **헤드리스 브라우저에는 PDF 뷰어가 없다.** 자동 검사는 「어떤 파일을 여는가」만 보고,
  실제 렌더링은 헤드 모드(`channel: 'chrome'`)로 따로 확인했다

## 8. 이번 세션에 잡은 결함 — 되풀이 방지

| 결함 | 증상 | 원인 |
|---|---|---|
| **「다시 편성」이 조용히 아무 일도 안 함** | 새로고침 직후 누르면 무반응 | 고친 것이 없으면 저장분의 `edit` 이 null(빈 편집은 저장 안 함)인데 핸들러가 초입에서 빠져나갔다. → 기준선에서 시작 |
| **React 중복 key** | `r4|0|0|미래혁신팀` 이 둘 | 엔진의 ②④ 는 **사람 단위**인데 키는 (날짜·세션·팀) 단위다. 한 팀이 한 세션에 둘이면 같은 키가 둘. → 키로 접는다 |
| **확정한 날에 새로 들어온 사람이 재통보에서 빠짐** | 면접관 일정이 말없이 늘어남 | `renotifyOf` 가 확정 스냅샷만 봤다. → `added` 종류 추가 |
| **드래그가 한 줄 아래에 떨어짐** (검증 스크립트) | 겨냥한 칸과 다른 칸에 놓임 | dnd-kit 은 **끌고 있는 카드의 사각형**으로 대상을 고른다(closestCenter). 테스트가 확인 없이 놓고 있었다. → `aim()` 도우미가 실제 `td.over` 를 보고 맞춘다 |
| **테두리 색이 안 먹음** | 지정해도 그대로 | `border` 축약형과 `.has-base-notice` 가 뒤에서 덮었다. → `--card-line` 변수 하나로 모음 |
| **고정 위치를 잡은 테스트가 어긋남** | 편성이 바뀌자 실패 | `placed[0]` + 첫 빈 칸 같은 고정 인덱스. → 조건에 맞는 짝을 **찾아서** 쓴다 |

**교훈이 하나 더 있다.** 드래그 중 **원본 카드에는 크기 변형을 걸면 안 된다** — 사각형이 흔들려
조준이 밀린다. 반면 **누를 때(`:active`)의 축소는 안전하다**: 중심 기준 축소는 중심 좌표를
바꾸지 않고, `closestCenter` 는 중심 거리로 고른다. 실측으로 확인했다(중심 이동 0px).

## 9. 자주 나온 질문 — 첫 타임(④)은 왜 어겨지나

사용자가 세 번 물었다. 답을 여기 박아 둔다.

**규칙:** `(slot === FS.am || slot === FS.pm) && demand[team] > minDemand`
→ 오전 첫(08:00)과 **오후 첫(13:00) 둘 다** 대상. 수요가 가장 적은 팀은 대상이 아니다
(프로세스개선팀 4 = 최소 4 → 표시 없음. 이건 규칙이 **의도한** 배치다).

**왜 어겨지나 — 두 경우가 다르다.**

- **미래혁신팀(17건): 못 피한 것.** 학사 구간 12칸에 13명이라 비둘기집으로 강제된다.
  1일차 8세션을 전부 써야 하므로 08:00·13:00 이 자동 포함된다
- **배터리기술팀(5건): 안 피한 것.** `1~5` 로 이어 앉히면 4번(13:00)이 낀다. 끊으면 첫 타임은
  피하지만 팀이 두 덩어리가 된다. **비용표가 연속 55 > 첫 타임 22** 로 이미 정해 놓았다

**중요:** 라이트 데모는 `Sched.schedule()` 을 직접 부른다. **전체 편성안을 비교하는 코드가 없다.**
「하루 더 쓰면 첫 타임을 피할 수 있는데?」를 저울질하지 않는다. 일수는 비교 결과가 아니라
**학력별 인원 ÷ 조 수**로 미리 자른 구간의 결과다. 비교하는 것은 `scheduleAuto()` 뿐이고
(정렬 키 `[일수, 좌석, ③+④]`), 우리는 조 수가 고정이라 쓰지 않는다.
