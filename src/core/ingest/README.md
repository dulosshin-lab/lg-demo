# ① ingest — 엑셀 → 행 목록

업무 5단계 중 **① 지원자 엑셀 정리**에 해당한다.

## 들어오는 것 / 나가는 것

```
Sheet    ──▶  parseTeam()      ──▶  ParsedTeam { rows, icol, iheader, how } + warnings[]
Sheet    ──▶  parseMaster()    ──▶  ParsedMaster { rows: Map<지원자번호, 전컬럼>, columns }
Sheet[]  ──▶  mergeAsMaster()  ──▶  ParsedMaster       ← 취합파일이 없을 때
```

`Sheet` 는 순수 데이터다(`grid: Cell[][]`). **이 폴더는 ExcelJS 를 모른다** —
엑셀 바이트를 `Sheet` 로 바꾸는 일은 `src/io/xlsx.ts` 가 한다.
엑셀 라이브러리를 갈아끼워도 이 폴더는 그대로다.

## 고치려면 어디를 보나

| 바꾸고 싶은 것 | 볼 파일 |
|---|---|
| **면접관 컬럼을 고르는 규칙** | `interviewer.ts` ← 대부분 여기다 |
| 헤더 행을 찾는 방법 | `headers.ts` `findHeaderRow()` |
| 표준 컬럼 목록 | `headers.ts` `STD` |
| 경고 문구 | `parseTeam.ts` |
| 날짜·수식 셀을 읽는 방법 | `../../io/xlsx.ts` `normalize()` |

## 면접관 컬럼 규칙

```
면접관 컬럼 = 헤더 텍스트가 있는 마지막 열
```

실 데이터 20개 파일(`data/` 8 + `data/demo-archive/` 12) 전부에서 그러했다.
컬럼 수가 22 · 49 · 52 · 55 로 갈리는데도 예외가 없었다. 헤더명만 4종이다:

| 헤더명 | 파일 수 |
|---|---|
| `면접관` | 16 |
| `팀 면접관` | 2 |
| `면접관 성명` | 2 |
| `인원` | 2 |

`인원` 처럼 `면접관` 이라는 글자가 없는 헤더가 있어서 **헤더명으로는 찾을 수 없다.**
그래서 헤더명은 찾는 수단이 아니라 확인 수단으로만 쓴다.

- 헤더에 `면접관` 포함 → `how: 'header'`, 경고 없음
- 그 외 → `how: 'position'` + `면접관 컬럼명이 비표준 → "인원"` 경고
- 마지막 열이 표준/마스터 컬럼 → 면접관 컬럼이 없는 파일로 본다 (`col: null`)
- 값이 사람 이름 모양이 아니면 → `값 패턴으로 추정` 경고.
  화면(`components/Warnings.tsx`)이 이 문구로 **사람 확인 필요** 배너를 띄운다

## 취합파일이 없을 때 (`mergeAsMaster`)

두 파일이 하는 일이 다르다.

```
희망지원자_{팀}.xlsx  →  누가 · 어느 팀이 · 누가 면접관인가   ← 편성의 짝
취합파일.xlsx         →  그 사람이 누구인가 (성명·학력·전공)  ← 살
```

**짝은 회신 파일에만 있다.** 취합파일 52개 컬럼에는 면접관이라는 개념 자체가 없다.
거꾸로 **살은 회신 파일에도 있다** — 회신 파일이 취합파일에서 뽑아 만든 것이라
`지원자 번호` · `한글성명` · `최종학력_학교유형` 을 그대로 이고 있고, `data/` 8개 전부가 그렇다.

그래서 취합파일이 없으면 회신 파일들을 그대로 마스터로 삼는다. 실측으로 대상 60명이
취합파일을 넣었을 때와 **완전히 일치**했다. 팀 회신이 먼저 오고 취합파일이 늦게 오는 것이
실무 순서라, 그동안 화면이 비어 있을 이유가 없다.

⚠️ **마지막 열(면접관)은 `columns` 에서 뺀다.** 이 집합은 회신 파일의 "표준 컬럼" 판정에
쓰이는데, 면접관 헤더가 거기 들어 있으면 `findInterviewerCol` 이 그 열을 표준 컬럼으로 보고
버린다 — 그러면 면접관을 아무도 못 찾아 **전원이 '면접관 미매칭' 으로 제외된다.**

## 검사

```bash
npm test -- ingest
```

- `__tests__/golden.test.ts` — 20개 실 파일에서 Python 파서(`legacy-server/parse_val.py`)와
  면접관 컬럼·명단이 완전히 같은지 대조한다. 기준값은 `tests/golden/parse.json`
- `__tests__/interviewer.test.ts` — 규칙 자체의 단위 검사. 규칙을 바꾸면 여기가 먼저 깨져야 한다
- `__tests__/masterless.test.ts` — 취합파일 없이 돌린 결과가 골든과 같은지. 이 경로는
  같은 결과를 내야만 편의이고, 다르면 위험이다
